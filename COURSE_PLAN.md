# Fundamentos de Desarrollo Web: HTML y CSS

## Resumen del Curso
Este curso introduce a estudiantes de secundaria a la creación de sitios web sencillos con HTML y CSS. **¡No requiere descargas!** Solo abre tu navegador web.

**Duración total**: ~40 minutos
**Público objetivo**: Estudiantes de 12 a 17 años sin experiencia en programación
**Prerrequisitos**: Ninguno
**Herramientas necesarias**: **¡Solo tu navegador web!** (Chrome, Firefox, Safari, Edge)

**📂 Repositorio de código fuente**: [https://github.com/upc-pre-202620-1asi0730-16712-wrunners/webdev-course-webrunners](https://github.com/upc-pre-202620-1asi0730-16712-wrunners/webdev-course-webrunners)

## Secuencia de la lección

### Lección 1: ¿Qué es una página web? Tu primer HTML (14:41 min)
- **Descripción**: Descubre de qué están hechos los sitios web, qué hacen HTML y CSS, y escribe tu primera página con un título y un párrafo.
- **Enlace**: [Ver la lección](https://youtu.be/n8GdcbU-HVs)
- **Consejos clave**: Sitios web = Contenido (HTML) + Estilo (CSS). Toda página tiene `<html>`, `<head>` y `<body>`.
- **Práctica**: [Clic para programar](https://codepen.io/pen/) 👈 **¡No necesitas registrarte!**

### Lección 2: Elementos HTML y primeros estilos CSS (8:24 min)
- **Descripción**: Agrega títulos, listas, imágenes y enlaces a tu página, y dale color, fuentes y bordes con CSS.
- **Enlace**: [Ver la lección](https://youtu.be/MWKh0JjKHFk)
- **Consejos clave**: Usa `<h1>`, `<p>`, `<ul>`, `<img>` y `<a>`. Una regla CSS tiene selector, propiedad y valor: `h1 { color: blue; }`.
- **Práctica HTML**: [Clic para programar](https://codepen.io/pen/) 👈 **¡Comienza al instante!**
- **Práctica CSS**: [Aplicar estilo con un clic](https://codepen.io/pen/) 👈 **¡No es necesario registrarse!**

### Lección 3: Taller guiado: tu página de perfil (11:18 min)
- **Descripción**: Combina HTML y CSS para crear una página de perfil personal, aprende a corregir errores comunes y personaliza tu resultado.
- **Enlace**: [Ver la lección](https://youtu.be/HWYjmZrfDMo)
- **Consejos clave**: Revisa que cada etiqueta esté cerrada y que cada regla CSS termine con `}`.
- **Proyecto Final**: [Crea tu perfil](https://codepen.io/pen/) 👈 **¡Cambia el texto y los colores a tu gusto!**

### Lección 4: ¿Qué viene después? Vue, .NET y cómo se conecta todo (5:30 min)
- **Descripción**: Conoce, de forma introductoria, qué otras tecnologías se usan para crear aplicaciones web más completas y cómo se comunican entre sí.
- **Enlace**: [Ver la lección](https://youtu.be/wXAmouezmR8)
- **Consejos clave**: HTML organiza, CSS presenta y el servidor procesa. Esta lección no tiene práctica de código.
- **Sigue aprendiendo**: [Documentación web de MDN](https://developer.mozilla.org/es/)
