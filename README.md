# Fundamentos de desarrollo web: HTML y CSS

Curso introductorio para estudiantes de secundaria de 12 a 17 años. No necesitas conocimientos previos ni instalar programas: puedes realizar todas las actividades desde tu navegador.

## Objetivos
- Reconocer qué es una página web y distinguir HTML de CSS.
- Utilizar títulos, párrafos, listas, enlaces e imágenes.
- Aplicar colores, fuentes, márgenes, bordes y centrado con CSS.
- Crear una página de perfil personal sencilla.
- Reconocer y corregir errores comunes.

## Requisitos
Un navegador moderno y un editor en línea gratuito, como [CodePen](https://codepen.io/pen/), [JSFiddle](https://jsfiddle.net/) o [Replit](https://replit.com/).

## Estructura
- `starter-files/`: ejercicios para comenzar.
- `completed-examples/`: soluciones para comparar al terminar.
- `scripts/`: guion de narración de las lecciones (no se necesita JavaScript).
- `COURSE_PLAN.md`: resumen, lecciones y enlaces del curso.

## Cómo realizar las prácticas
1. Abre [CodePen](https://codepen.io/pen/).
2. Abre el archivo del ejercicio en `starter-files/`.
3. Si el archivo incluye `<html>`, `<head>` y `<body>`, copia **solo el contenido dentro de `<body>`** al panel HTML de CodePen. Si incluye un bloque `<style>`, copia su contenido (sin las etiquetas `<style>`) al panel CSS.
4. Cuando el ejercicio tiene un archivo `.css`, copia ese archivo al panel CSS de CodePen.
5. Prueba cambios y compara tu resultado con el archivo correspondiente de `completed-examples/`.
6. Si deseas guardar tu progreso, utiliza las opciones que ofrezca el editor en línea.
